> 日期：2026-10-31

## 0. 一页纸总览

### 0.1 产品一句话

你是数字世界里的养鸽人：配对、养护、训练出有血统与赛绩的鸽子；把它们送进公棚证明手艺；在交易与拍卖里经营资产；进阶后可执令开棚办赛。更往后，你还能凭眼光参与映射真实公棚的场外份额赛——两条乐趣分开：**手艺养自家鸽，眼光参与真天空。**

### 0.2 两条乐趣宪法（全版本有效）

| | 数字线（先做） | 仿真线（后做） |
|--|----------------|----------------|
| 鸽子归属 | **玩家的**数字鸽 | **不属于玩家**的真实运动员标的 |
| 拼什么 | 养殖、训练、配对、择赛等**手艺** | 选鸽、买份额、读赛况等**眼光** |
| 教什么 | 通过好玩的真实感，学会「真玩鸽」的决策逻辑 | 学会看赛、看状态、看赛线 |
| V1 是否出现 | 是（核心） | 否 |

### 0.3 玩家角色演进

```
鸽友（养/训/买卖）
  → 参赛者（送官方公棚）
    → 资深养家 / 商人（拍卖与市场）
      → 办赛方（公棚建设令牌 → 玩家公棚）
        → 眼光客（仿真场外份额，可选平行身份）
```

### 0.4 版本地图（到最终完整版）

| 版本 | 主题一句话 | 核心交付 |
|------|------------|----------|
| **V1.0** | 棚里立住 | 养成、配对繁殖、健康因果、轻竞技、交易拍卖雏形、商城 |
| **V1.5** | 官方公棚开门 | 送鸽→训放→关赛→成绩→奖金/荣誉；养成追求与赛场打通 |
| **V2.0** | 经济与身份成熟 | 深度血统/赛绩体系、完整市场、赛季制、排行与图鉴 |
| **V2.5** | 玩家办赛 | 公棚建设令牌、玩家公棚收鸽办赛、信誉与抽成 |
| **V3.0** | 仿真场外 | 真实公棚映射运动员、多人份额、按真赛绩结算 |
| **V3.5** | 双宇宙合流 | 资讯、赛历、跨线荣誉、深度社交与「鸽友」圈层 |
| **V4.0** | 数字物种愿景 | 繁育与生存更贴近生物定律的「数字鸽子物种」深化 |

## 1. 设计原则（全版本）

1. **好玩的真实感**：决策逻辑像真鸽界；等待与失败成本按游戏手感调。  
2. **损失可归因**：鸽子生病、伤残、死亡、炸棚式失败，必须能追溯到玩家行为（含长期忽视）；禁止无意义随机灭鸽。  
3. **成绩有因果**：表现与血统、训练、营养、健康、赛线匹配正相关（可加天气等公开变量）。  
4. **两条线不糊**：数字鸽≠仿真运动员；仿真线永不要求「用养成鸽去飞真公棚」。  
5. **官方公棚是脚手架**：早期官方办赛；终局以玩家公棚生态为主，官方退居校准与品牌赛。  
6. **令牌产生庄家**：开棚权来自稀缺「公棚建设令牌」（可转让），而非人人一键开棚。  
7. **血统可信**：血统与关键所有权/赛绩记录以不可篡改账本呈现（链为手段，玩家感知是「血统书可信」）。  
8. **V1 先做游戏**：仿真板块可不上；先把养与官方赛做成上瘾闭环。

### 1.1 时间与节奏原则（不定死倍率，定标准）

对标养成/经营类常见手感：

| 尺度 | 设计目标 |
|------|----------|
| 单次会话（5–15 分钟） | 有喂养/检查/训练/交易等可完成动作 |
| 单日 | 幼鸽有可见成长；成鸽有训练或备赛反馈 |
| 数日–两周 | 一羽从新生到「具备送棚资格」的主成长弧 |
| 赛季（数周–数月） | 血统积累、赛绩簿、排行榜、大型官方赛 |

孵化、换羽、路训周期用**游戏内阶段**表达真实结构，用加速/离线进度/道具调节等待，避免「学真实＝学无聊等待」。

## 2. 世界观与对象模型

### 2.1 核心对象

- **玩家鸽棚**：饲养、配对、训练、医疗的主场景。  
- **数字鸽**：有基因/血统、表型、健康、状态、赛绩、所有者。  
- **物品**：饲料、保健品、药品、训练器械、巢箱等。  
- **公棚**：收鸽、统一饲养训放、出成绩、发奖（官方 → 后期玩家）。  
- **市场**：玩家交易、拍卖行、令牌市场。  
- **仿真运动员（V3+）**：映射真实公棚赛鸽的只读竞体 + 可购份额。

### 2.2 数字鸽关键维度（概念层）

- **血统**：父母与系谱、近交系数示意、著名祖先引用。  
- **适性**：短程爆发 / 中程 / 耐翔；对恶劣天气、山区/平原等倾向。  
- **状态**：体能、疲劳、伤病、体重、精神（可简化为少数字段 + 可读文案）。  
- **赛绩簿**：关次、名次、分速、鸽王分、团体贡献。  
- **经济身份**：是否上架、拍卖中、已送棚锁定等。

### 2.3 失败与死亡规则（概念）

触发源仅限例如：错误饲喂、过量/不足训练、延误治疗、带病强赛、卫生长期失控、不当用药、送棚时机极差等。  
每条重大损失提供**复盘原因**（教真实决策，而不是惩罚黑箱）。

## 3. V1.0 — 棚里立住（不上仿真、可无正式公棚大奖赛）

### 3.1 目标

让玩家承认：**「这些鸽子是我的，我正在学养，并且已经上瘾。」**

主追求权重（混搭 D）：

| 追求 | 权重意向 | 内容 |
|------|----------|------|
| 育种图鉴 / 血统树 | 高 | 配对实验、系谱收集、性状稳定/杂交 |
| 交易拍卖赚差价 | 中高 | 早期经济动力与社交曝光 |
| 棚内轻竞技 | 中 | 家飞、短距路训榜、状态评分赛——为 V1.5 公棚打样 |

### 3.2 玩法模块

1. **账号与棚**：创建鸽棚、基础设施、引导教程（真术语 + 游戏步骤）。  
2. **获得初鸽**：新手赠鸽、商城种鸽蛋/幼鸽、市场买入。  
3. **日常养护**：喂食配方、饮水卫生、观察状态；忽视会累积负面。  
4. **训练**：家飞 → 短距路训阶梯；过度训练有伤病风险。  
5. **健康**：常见病逻辑（可归因）、药品商城、疗程与停药。  
6. **配对繁殖**：选配对、产蛋、孵化、育雏独立；记录血统。  
7. **图鉴与成就**：品系、眼砂/羽色等收集向（服务好玩，不替代因果）。  
8. **商城**：用品、药品、饲料、少量外观/棚装。  
9. **玩家交易 + 平台手续费**：鸽与物品。  
10. **拍卖行雏形**：定时拍、出价、成交结算。  
11. **轻竞技**：棚内赛/地区练习赛（官方 NPC 裁判），小额奖金或实物奖励池（按发行策略），重点练「送赛前状态」心智。  
12. **血统展示**：可验证的血统书 UI（链或等价可信账本可先做最小可信层）。

### 3.3 明确不做（V1.0）

- 仿真场外份额赛  
- 玩家公棚 / 建设令牌  
- 大型多关官方公棚终局赛（可预告）  
- 「数字物种」级生物硬核模拟  

### 3.4 V1.0 成功标准（设计视角）

- 新玩家能复述：喂、训、配、治四件要事  
- 出现自然讨论：配对思路、拍卖捡漏、路训榜  
- 愿意为种鸽、药品、拍卖加价付费（或虚拟经济深度消耗）

## 4. V1.5 — 官方公棚组织的比赛

### 4.1 目标

把养成从「棚内自嗨」升级为：**统一规则下的手艺证明。**

### 4.2 公棚赛季循环（数字）

1. **预定 / 交鸽**：年龄与健康门槛；锁定期间所有权仍在玩家，但不可交易或限制交易。  
2. **开家与家飞**：公棚侧统一叙事与状态同步。  
3. **路训阶梯**：公开训放成绩（眼光训练的预演，但仍是你的鸽）。  
4. **收费站 / 清棚**：能否继续参赛的抉择（止损心智）。  
5. **关赛**：热身 → 预赛 → 决赛等；关关淘汰或规程化规则。  
6. **鸽王 / 团体**：多关综合与组队规则。  
7. **成绩与奖金**：固定规程奖；荣誉写入赛绩簿与血统叙事。  
8. **赛后**：领回、拍卖优胜鸽（分成）、留种决策。

### 4.3 与 V1.0 的衔接

- 轻竞技里教过的「状态、距离、风险」在公棚放大  
- 交易市场出现「有公棚资格 / 有训放亮点」的溢价  
- 育种目标从「好看图鉴」转向「适某赛线的种」

### 4.4 官方公棚定位

- 规则示范者、信任校准者、奖金与流量的启动器  
- 为 V2.5 玩家公棚提供「什么叫好公棚」的对照样本

## 5. V2.0 — 经济与身份成熟

### 5.1 目标

赛季化、身份化、市场深度化：**养家 / 商人 / 选手** 分途都有终局感。

### 5.2 增强模块

1. **赛季制**：春/秋或全球统一赛季；赛季任务与赛季荣誉。  
2. **深度血统**：近亲复壮/杂交策略的可读反馈；「黄金配对」纪录。  
3. **赛绩含金量**：不同公棚/赛事等级加权；鸽王体系完善。  
4. **完整拍卖生态**：专场（冠军夜、种鸽夜）、保留价、分成展示。  
5. **排行榜矩阵**：育种、单关、鸽王、商人利润、稳定归巢等多元榜（避免唯充值）。  
6. **棚设施进阶**：容量、医疗、训练效率等经营层（仍服务养鸽，不做成无趣的数值厂）。  
7. **中英内容与支付体验打磨**：USDT 流程、商店页、客服与争议（拍卖/交易）。  
8. **可信血统账本完善**：关键变更上链或等价公示。

### 5.3 仍可不做

- 玩家开棚可只预告  
- 仿真线仍可不上

## 6. V2.5 — 公棚建设令牌与玩家办赛

### 6.1 目标

世界从「官方办赛」转为**玩家可成为庄家/主办方**的生态。

### 6.2 公棚建设令牌

- **稀缺**：总量或产出曲线可控。  
- **获取要显得公平**：赛季高成就、贡献销毁拍、特殊赛事冠军、长期活跃门槛等组合（具体配方可另案）。  
- **可转让**：令牌本身是高价值资产，平台可抽手续费。  
- **用途**：消耗或绑定后建立公棚；也可纯投机倒卖。

### 6.3 玩家公棚玩法

1. 选址/命名/规程模板（距离、关次、费用、奖金结构、录取名次）。  
2. 收鸽、饲养叙事、训放、集鸽、出成绩。  
3. **抽成与风险**：主办方收益来自参赛费结构；需承担口碑（拖奖金、规程朝令夕改 → 信誉崩）。  
4. **信誉体系**：履约、投诉、历史奖金发放、参赛羽数。  
5. 官方逐步让出日常场次，保留「品牌校准赛」。

### 6.4 设计要点

- 令牌决定「有没有资格开」；信誉决定「有没有人来」  
- 防止纯掠夺性公棚：保证金、规程锁定、成绩公示等（产品手段，非某国法律讨论）

## 7. V3.0 — 仿真赛（真实公棚场外份额）

### 7.1 目标

上线第二乐趣：**鸽子不是你的，你拼眼光。**

### 7.2 核心规则概念

1. 基于合作真实公棚赛历，生成/同步 **赛鸽运动员** 条目。  
2. 玩家可购买该羽的**份额**；**一羽可被多人持有**。  
3. 结算以**线下实际比赛成绩**为准。  
4. 玩的是资讯、判断、仓位与赛日体验，不是喂养。  
5. 可与二级市场份额转让、热度定价（谨慎设计泡沫与爽感）。

### 7.3 与数字线关系

- 账户可同时是养家与眼光客，**荣誉分榜**  
- 仿真不吞噬数字：数字赛绩仍是育种与开棚的主叙事  
- 官方/合作方驱动赛历；不同于玩家数字公棚

### 7.4 为何放在 V3

依赖真实合作、赛果信任、份额清算叙事；需核心游戏已好玩、经济已稳定。

## 8. V3.5 — 双宇宙合流与鸽友社交

### 8.1 目标

线上玩法成熟后，强化**圈层感**与跨线体验（为线下鸽友社交「引气」，但不把线下交付当 V1 KPI）。

### 8.2 模块方向

1. **统一赛历与资讯中心**：数字公棚日程 + 仿真真实赛历。  
2. **跨线荣誉展示**：养家成就与眼光成就同屏，身份可切换皮肤。  
3. **社群**：棚主页、关注、动态（配对成功、关赛归巢、份额战报）。  
4. **联盟/俱乐部**：团体赛报名、院内棚文化向的轻组织。  
5. **引气线下**：活动码、赛季线下见面会、合作公棚观赛（运营向，非核心玩法必选项）。

## 9. V4.0 — 数字鸽子物种愿景

### 9.1 目标

在游戏大卖、数据与模型足够后，将数字鸽从「强游戏规则的生物」推进到**更遵循物理世界生物定律的数字物种**（繁育、遗传、健康、行为）。

### 9.2 原则

- 不推翻 V1–V3 的玩家资产与血统史，而是**加深模拟层**  
- 仍保持「好玩」：生物真实 ≠ 无反馈折磨  
- 可为科研/内容/品牌叙事服务，但产品上仍是游戏

## 11. 经济与激励（概念层）

### 11.1 价值来源

- 种鸽与赛绩溢价  
- 耗材与医疗（服务养成深度，忌纯折磨）  
- 交易/拍卖手续费  
- 公棚参赛费与办赛抽成（V2.5+）  
- 仿真份额相关费用（V3+）  
- 令牌投机与消耗  

### 11.2 沉没与出口

- 训练与参赛的风险损失（可归因）  
- 失败育种与淘汰  
- 手续费与公棚费用  
- 外观/棚装等非战力消耗（调节向）

### 11.3 设计警戒

- 数字赛荣誉不能被仿真赚钱完全替代  
- 拍卖泡沫可有，但需赛绩与血统锚定，避免纯击鼓传花无内容

## 12. 教学与「学会真玩鸽」

- 术语真实：足环、训放、清棚、关赛、鸽王、分速、留种等  
- 每次重大失败给因果复盘  
- 可选「教练模式」解说为什么这样配、为什么这关该停
