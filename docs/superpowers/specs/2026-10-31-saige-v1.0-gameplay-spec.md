> 状态：供评审的详细规格（承接总策划案）  
> 日期：2026-10-31  
> 父文档：`2026-10-31-saige-game-gdd-by-version.md`  
> 范围：**仅 V1.0**；不含官方公棚大奖赛、玩家公棚令牌、仿真场外

## 1. V1.0 目标与边界

### 1.1 一句话

玩家在自己的数字鸽棚里，学会喂、训、配、治，用血统树、交易拍卖和棚内轻竞技玩起来——并为 V1.5 官方公棚预留接口与心智。

### 1.2 成功标准

| 类型 | 标准 |
|------|------|
| 认知 | 新手能复述：喂、训、配、治 |
| 行为 | 自然出现配对讨论、拍卖捡漏、路训榜竞争 |
| 经济 | 种鸽 / 药品 / 拍卖形成付费或深度消耗意愿 |
| 衔接 | 玩家理解「状态好才能送赛」；数据模型预留公棚锁定字段 |

### 1.3 明确不做

- 仿真场外份额、真实公棚运动员  
- 公棚建设令牌 / 玩家办赛  
- 多关官方公棚大奖赛（可 UI 预告「即将开放」）  
- 硬核生物物种模拟（V4 愿景）  
- 复杂天气赛线系统的完整版（V1.5+ 加深）

### 1.4 主追求权重

| 追求 | 权重 | 设计职责 |
|------|------|----------|
| 育种图鉴 / 血统树 | 高 | 长期目标与内容深度 |
| 交易 / 拍卖 | 中高 | 社交曝光与经济动力 |
| 棚内轻竞技 | 中 | 验证手艺、预演公棚心智 |

## 2. 玩家旅程（V1.0）

```
注册 / 选语言（中|英）
  → 建棚命名 + 新手引导（约 10–15 分钟可中断）
    → 获得起步鸽（赠羽 + 可选购）
      → 日环：检查状态 → 喂养/卫生 → 训练或休息 → 医疗
        → 解锁配对 → 第一窝繁殖
          → 上架交易 / 参与拍卖
            → 报名棚内轻竞技
              → 中期目标：图鉴、榜、黄金配对萌芽、攒「未来送公棚」的好羽
```

### 2.1 新手引导必教四事

1. **喂**：配方影响体重与状态，不是点一下加血。  
2. **训**：家飞→路训有阶梯；过量会伤。  
3. **配**：看血统与适性，不是唯战力数值。  
4. **治**：有症状要疗程；拖病会恶化（玩家行为导致）。

引导结束时应送出一羽「有小缺陷需玩家处理」的鸽，强制体验一次归因医疗，而不是完美宠物。

## 3. 时间与节奏规格

### 3.1 设计标尺（倍率可调，标尺锁定）

| 真实体验目标 | 游戏内建议落点（初值，可调） |
|--------------|------------------------------|
| 单次有意义操作 | 打开即有 1–3 羽需处理 |
| 产蛋→孵化完成 | **4–8 小时**真实时间（可分段加速道具） |
| 出壳→育雏独立 | **24–48 小时** |
| 独立→「轻竞技适龄」 | **3–7 天** |
| 独立→「未来公棚适龄」预告标准 | **7–14 天**（V1.0 只显示资格条，不开放送棚） |

离线：养护与孵化继续推进；训练任务不自动完成（防挂机练废）。  
加速：允许有限加速道具（孵化/成长），**不可加速「伤病痊愈」到无视疗程**（避免架空医疗线）。

### 3.2 日检节奏

建议每日刷新一次「棚务清单」：未喂、饮水脏、疲劳过高、疗程中、可训、可配。  
连续 **N 日**（初值 3）忽略清单中的危急项 → 进入恶化链路（见健康章）。

## 4. 鸽棚与容量

### 4.1 棚

- 创建时命名、地区展示名（可虚构）、语言跟随账号。  
- 基础槽位：种鸽区 / 赛训区 / 育雏区（可同屏分区，逻辑分栏即可）。  
- V1.0 设施：基础巢箱、食槽、饮水、简易医疗柜、基础训练标记点。  
- 扩容：商城或成就解锁格数（避免一上来无限羽导致养成垮掉）。

### 4.2 容量规则（已拍板）

**设计意图**：够玩育种与轻竞技，逼玩家淘汰/出售/寄售，不做无限仓鼠笼。

| 区 | 初始格 | 单区硬上限（V1.0） | 扩容步进 |
|----|--------|-------------------|----------|
| 种鸽区 | 4 | 12 | +2 / 次 |
| 赛训区 | 6 | 16 | +2 / 次 |
| 育雏区 | 4 | 10 | +2 / 次 |

- **全棚存活鸽硬帽（V1.0）**：**36**（蛋占育雏格，计入全棚帽；纪念堂已故鸽不占）。  
- **软警告**：任一区占用 ≥80%，或全棚 ≥28，日检提示「该淘汰、出售或停配」。  
- **扩容**：巢币或 IAP 礼包；次数越多单价越高；触及硬帽后只能减羽，不可再扩。  
- **不做寄养**（V1.0）。  
- 推荐舒适经营羽数：**12–20**（引导与成就按此口径写文案）。

## 5. 数字鸽数据模型（V1.0）

### 5.1 身份

| 字段 | 说明 |
|------|------|
| pigeonId | 全局唯一 |
| ringNo | 展示用足环号（年度+序号风格） |
| name | 可选昵称 |
| ownerId | 当前所有者 |
| sex | 雄/雌 |
| birthAt | 出壳时间 |
| lifeStage | 蛋 / 雏 / 幼 / 成 / 退役种（V1.0 简化） |
| statusFlags | 上架中、拍卖中、竞赛锁定、疗程中等 |

### 5.2 血统（展示 + 遗传输入）

- 父母 ID、祖代至少 **3 代**可查 UI。  
- **品系命名：一律虚构**（已拍板）。听感可像国际鸽界，禁止未授权真实名家姓名/商标；品系对应不同基因频率与性状协方差，不是换皮标签。  
- **近交与遗传：严格按遗传学建模**（已拍板，见 §10.5）；配对 UI 展示亲缘 / F 等可读译解，不设行政禁配。  
- 血统书页：可分享；关键铸造/变更写「可信记录」（实现可以是链或服务端签名日志，V1.0 最小可信即可）。

### 5.3 隐式基因 → 显式适性（玩家可读）

V1.0 不要让玩家面对 50 个隐藏小数。建议：

**隐藏层（系统用）**：速度潜能、耐力潜能、抗逆、归巢稳定、学习速度、体质。  
**展示层（玩家看）**：

| 展示 | 来源 |
|------|------|
| 适性雷达 | 短 / 中 / 耐翔 |
| 体质 | 易病↔强健 |
| 气质 | 兴奋↔稳 |
| 血统摘要文案 | 由父母与品系生成 |

成绩公式用隐藏层；UI 用展示层 + 复盘文案教因果。

### 5.4 状态条（日常操作对象）

| 状态 | 作用 |
|------|------|
| 饱食 | 过饥/过饱都伤表现与健康 |
| 水分/卫生关联 | 饮水与棚卫生影响发病 |
| 疲劳 | 训练与竞赛消耗；高疲劳禁强训 |
| 体能/肌肉 | 训练正向，需恢复 |
| 体重区间 | 偏离适重 → 表现惩罚 |
| 心情/精神 | 影响食欲与训练收益（轻量） |
| 伤病槽 | 见健康章 |

### 5.5 赛绩簿（V1.0）

记录轻竞技：项目、距离档、名次、分速、日期、复盘标签。  
为 V1.5 预留：公棚 ID、关次、鸽王分字段（空置）。

## 7. 日常养护

### 7.1 喂养

- 饲料分档：维持粮、育雏粮、赛训粮、恢复粮等（名称可中英对照真术语）。  
- 每羽或分区设定配方；错误配方（如雏鸟长期赛训粮）→ 体重/发病归因。  
- 喂养是**日程行为**：可一键按配方执行，但配方对错由玩家负责。

### 7.2 饮水与卫生

- 饮水清洁度随时间下降；一键清洁为日课。  
- 长期不清洁 → 提高消化道/呼吸类病权重（仍算玩家忽视）。

### 7.3 观察

- 鸽卡显示异常提示（精神差、粪便示意、翅膀下垂等文案/图标）。  
- 高级信息可部分解锁（兽医笔记、图鉴），避免开局信息爆炸。

## 8. 训练

### 8.1 阶梯

| 阶段 | 内容 | 解锁 |
|------|------|------|
| 家飞 | 棚周飞行，降疲劳累积慢，建基础 | 幼鸽独立后 |
| 短距路训 | 数公里级阶梯（游戏抽象距离档） | 家飞达标 |
| 中距预习 | 更长一档，为 V1.5 预告 | 路训次数/成绩门槛 |

### 8.2 规则

- 每日可训次数受疲劳与伤病限制。  
- **过量**：连续强训 → 肌肉伤 / 翼伤风险上升（可归因）。  
- **不足**：长期只关养 → 体能下降、轻竞技表现差（可归因）。  
- 训练产生「状态曲线」：赛前需要找峰值窗口（轻竞技报名时提示）。

### 8.3 反馈

训后给短报：距离档完成度、分速估计、疲劳变化、风险提示。  
榜：地区/全球家飞积分榜、短距路训榜（周榜重置，防绝望）。

## 9. 健康、医疗与死亡

### 9.1 原则

- 无「天降猝死」。  
- 每条病都有：**诱因（玩家侧）→ 症状 → 可检测 → 疗程 → 延误后果**。  
- 重大损失弹 **复盘卡**：时间线列出忽视喂养/强训/未治疗等。

### 9.2 V1.0 病症池（建议 6 类内）

| 类型 | 典型诱因 | 治疗方向 |
|------|----------|----------|
| 消化不良/嗦囊问题 | 错粮、过食、卫生差 | 停食调整、消化药、清洁 |
| 呼吸道轻症 | 潮湿脏棚、受凉抽象事件+忽视 | 隔离、疗程药 |
| 寄生虫 | 卫生长期差 | 驱虫疗程 |
| 肌肉拉伤 | 过量训练 | 强制休息+外用/恢复项 |
| 翼伤 | 强训/带伤参赛 | 长休，禁训禁赛 |
| 传染风险 | 病鸽未隔离 | 棚内扩散（惩罚忽视隔离） |

### 9.3 疗程

- 药品来自商城；疗程有天数；期间限制训练/参赛。  
- 乱用药（不对症）→ 无效 + 可能肝肾抽象惩罚（轻量）。  
- 拖治疗：阶段恶化 → 慢性 → 死亡或退役强制。

### 9.4 死亡与退役

- 死亡：进入纪念/图鉴「失落」，血统树保留为祖先节点。  
- 可设「濒死抢救」高价项（仍须玩家操作触发，不自动）。  
- 年龄老化 V1.0 可极轻或不做自然老死，以免与「可归因」冲突；用伤病与退役表达生命周期。

## 10. 配对与繁殖

### 10.1 配对

- 一雄一雌占巢；需双成鸽、非疗程、非锁定。  
- 配对前展示：适性对比、**亲缘系数 / 近交系数 F 预估**、历史赛绩、子代期望与方差（科学区间，保留抽样惊喜）。  
- **不禁止近亲配**；后果由遗传模型结算，不设行政软锁。  
- 确认后进入产蛋倒计时。

### 10.2 繁殖流程

1. 产蛋（常 1–2 枚，游戏可固定 2 枚简化）  
2. 孵化（见时间标尺）  
3. 出壳占育雏格  
4. 育雏期喂养逻辑偏向育雏粮  
5. 独立 → 转入幼鸽/赛训区  
6. 写入血统书（父母、出壳时、可信记录、本窝 F 与关键基因型摘要）

### 10.3 育种策略空间（V1.0 要让玩家「玩得起来」）

策略名称服务教学，底层仍是遗传：

- **系内选配 / 近交**：提高纯合、固定理想等位基因；同时推高 F → **近交衰退**落在体质、育雏成功率、抗病等适应度性状  
- **远交 / 品系间杂交**：期望**杂种优势**（尤适应度与稳健），但可能打散已固定的竞赛特长  
- **种赛配**：高育种价值个体 × 高表现表现个体——改变的是亲本育种值与成绩记录在选择指数里的权重，不是玄学buff  

每窝结束给「育种小结」：本窝 F、关键性状育种值估计、是否朝选择目标移动。

### 10.4 图鉴

- 虚构品系、羽色、眼砂（或简化外观性状）、成就鸽（路训冠军父母等）。  
- 图鉴奖励：扩容、外观、加速道具——**不直接发满级战神鸽**。

### 10.5 遗传学规格（已拍板：严格遵循科学）

> 气质仍是「好玩的真实感」：模型要科学，界面要可读，不为难玩家做题。

**必须遵守的建模原则：**

1. **数量性状**（速度潜能、耐力、体质等）：多基因 + 环境；表现型 = 育种值 + 环境偏差（训练/营养/健康进入环境项）。  
2. **质量性状**（部分羽色等）：按孟德尔或已知显隐/伴性规则；不可「点按钮改色」。  
3. **亲缘与近交**：由系谱计算亲缘系数、子代近交系数 **F**；禁止用假随机代替系谱。  
4. **近交衰退**：F 上升对适应度相关性状施加科学方向的惩罚期望（存活、育雏、抗病、生育）；竞赛特长等位基因仍可借近交提高纯合固定——**双刃由同一套遗传得出**，不做「近交必出冠军」或「近交必禁」的行政规则。  
5. **杂种优势**：低亲缘、差异较大的品系/群体杂交时，适应度性状给有上限的优势期望；不自动等于竞赛每一项都变最强。  
6. **选择响应**：玩家谁留种、谁淘汰，应能在后续窝次看到育种值朝选择方向移动（可教「选择差」直觉）。  
7. **随机性**：减数分裂抽样与有限环境噪声允许；禁止与系谱无关的「隐藏改父母」。  

**V1.0 简化许可（不违背科学，只减阶）：**

- 用中等数量的 QTL/性状模块近似，不必全基因组。  
- 突变率极低或仅用于长期运营事件；开局不以高频随机突变当玩法。  
- 教学用「育种值条 / 风险灯」翻译 F 与方差，详细公式放内部数值文。

## 11. 轻竞技（V1.0 赛事）

### 11.1 定位

官方 NPC 承办的**练习赛 / 地区赛**，教「选羽、盯状态、承担风险」；奖金与荣誉为辅，为 V1.5 打样。

### 11.2 赛事类型

| 类型 | 说明 |
|------|------|
| 家飞积分赛 | 周期内家飞表现折算，低风险 |
| 短距路训公开赛 | 报名费可选；按分速/名次 |
| 状态评分赛 | 裁判抽象分：体重、疲劳、伤病、训练完成度（教备赛） |
| 新秀赛 | 限幼鸽，降低被老鸽碾压 |

### 11.3 报名规则

- 年龄/性别/伤病门槛。  
- 报名即短时锁定（不可卖）。  
- 带伤、过劳可强行报名 → 成绩差或加重伤（复盘可归因）。

### 11.4 结算

- 公开用种子+鸽子属性+状态+轻量随机（随机是「发挥波动」，不是无端倪死鸽）。  
- 发奖：**仅巢币 + 用品/外观/加速便利**（已拍板；V1.0 不发 USDT）。  
- 成绩写入赛绩簿与鸽卡。

### 11.5 排行

- 周榜：路训、新秀、养家活跃。  
- 赛季预告榜：为 V1.5「官方公棚资格分」暖场（可只展示，不消耗）。

## 12. 商城

### 12.1 品类

| 类 | 例子 | 备注 |
|----|------|------|
| 饲料 | 各配方粮 | 高频消耗 |
| 药品 | 对症疗程 | 中频，承接医疗 |
| 用品 | 巢箱、清洁、隔离笼 | 设施与卫生 |

### 12.2 支付（已拍板）

- **V1.0：Apple IAP（Apple Pay 等商店支付）买入游戏币「巢币」**（及可能的巢币礼包/月卡形态，具体 SKU 另表）。  
- **USDT / 链上支付：不进入 V1.0**，留待后续版本。  
- 商城标价、玩家交易与拍卖：**一律以巢币结算**。  
- 中英商品名与说明；IAP 商品遵守 App Store 展示规范。

## 13. 玩家交易

### 13.1 规则

- 可交易：非锁定鸽、非拍卖中鸽、物品。  
- 上架：**巢币**定价、展示血统摘要与赛绩、有效期。  
- 成交：平台抽成（初值建议 **2%–5%**，可调），抽成收巢币。  
- 交易冷却：防瞬时倒手刷榜可加短冷却（可选）。

### 13.2 信任

- 鸽卡信息以服务器为准；血统书只读。  
- 举报表单（骗描述等）——V1.0 做最小人工/规则处理流程说明即可。

---

## 14. 拍卖行（雏形）

### 14.1 流程

1. 卖家设定**巢币**起拍价、保留价（可选）、时长（如 6h/12h/24h）。  
2. 公开展示血统与赛绩。  
3. 出价；结束时最高价成交；流拍归还。  
4. 平台抽成（可略高于普通交易，如 **5%–8%**），收巢币。  

### 14.2 V1.0 专场（轻量）

- 每日「新手捡漏」官方辅拍（系统回收鸽或运营投放）。  
- 每周「种鸽夜」玩家送拍聚合。  

不做：复杂拍卖行会费、实时千人喊价特效（可后补）。

## 15. 经济初值框架（可调数值，定关系）

### 15.1 货币（已拍板）

| 货币 | V1.0 角色 |
|------|-----------|
| **巢币** | 唯一流通结算货币：饲料、药品、扩容、商城鸽、交易、拍卖、抽成 |
| **IAP → 巢币** | 玩家通过 App Store（Apple Pay 等）购买巢币或含巢币礼包 |
| **USDT** | **不上 V1.0**；后续版本再开 |

- 轻竞技与日常产出：巢币 + 物品（不产出法币/U）。  
- 巢币是否可「卖出成现金」：V1.0 **不可以**（标准 IAP 游戏币闭环）。  
- 玩家间交易：巢币点对点，平台抽成，不做法币提现。

### 15.2 价值锚（示意）

| 物 | 相对锚 |
|----|--------|
| 一天饲料（一羽） | 1 份巢币单位 |
| 基础疗程 | 3–10 日饲料 |
| 普通幼鸽市场 | 30–100 日饲料 |
| 有亮点赛绩成鸽 | 数倍幼鸽 |
| 扩容 +2 格 | 中高消费，随次数涨价 |
| 接近 36 帽时 | 引导出售/淘汰，不卖「解帽外挂」 |

具体数字进数值表另册；此处锁的是**相对关系**。

## 16. 表现因果（轻竞技结算概念）

```
表现 ≈ 适性匹配(距离档)
      × 状态(体重/疲劳/伤病)
      × 训练准备度
      × 营养阶段
      × 发挥波动(小)
```

复盘文案必须能指出最弱的一项（例如「疲劳过高」「适性偏耐翔但赛短距」），完成「好玩的真实感」教学。
