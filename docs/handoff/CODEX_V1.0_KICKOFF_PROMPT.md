## 产品一句话（V1.0）

玩家经营数字鸽棚：学会 **喂、训、配、治**；用 **血统育种、交易拍卖、棚内轻竞技** 形成闭环；气质是 **好玩的真实感**。  
**不上**：仿真场外份额、玩家公棚令牌、官方公棚多关大奖赛（仅可预告）、USDT。

两条长期宪法（V1.0 只做数字线）：

| 线 | 归属 | 拼什么 | V1.0 |
|----|------|--------|------|
| 数字线 | 玩家的鸽 | 手艺（养训配治） | **做** |
| 仿真线 | 非玩家的真赛映射 | 眼光（份额） | **不做** |

## V1.0 必须交付的系统

按推荐实现顺序推进（可微调，但勿跳过遗传与状态机去堆皮肤）：

### M0 — 工程地基

- 选定并写明技术栈（iOS 上架优先；需支持 IAP、推送可选、中英）。若仓库空白：先提交一页《技术选型提案》再大规模写业务代码。  
- 账号、鸽棚、鸽子、物品、订单的基础数据模型与 API/本地存储方案。  
- CI / 可在模拟器或真机跑通的空壳 App。  
- 配置化数值入口（便于策划后补 `economy` / `genetics` / `care` 表）。

### M1 — 棚与日环

- 建棚、分区：种鸽区 / 赛训区 / 育雏区。  
- **容量（已拍板）**：初始格 4 / 6 / 4；分区硬上限 12 / 16 / 10；**全棚存活硬帽 36**；区占用 ≥80% 或全棚 ≥28 软警告；推荐舒适 12–20 羽。  
- 日检清单：未喂、饮水脏、疲劳、疗程、可训、可配。  
- 喂养配方、饮水卫生；忽视累积恶化（可归因）。

### M2 — 训练与健康

- 家飞 → 短距路训（中距预习可做弱解锁）。  
- 过量/不足训练的伤病风险；训后短报。  
- 病症池按规格（消化、呼吸、寄生虫、肌伤、翼伤、传染/未隔离等）。  
- **死亡/损失必须可归因于玩家行为**；重大损失出复盘卡。  
- 疗程药：不可加速到「无视疗程」。

### M3 — 遗传与繁殖（核心难度）

- **严格遵循遗传学**（规格 §10.5）：数量性状多基因、质量性状孟德尔/显隐、系谱算亲缘与近交系数 F、近交衰退、杂种优势、选择响应。  
- **允许近亲配**，不设行政禁配。  
- 品系 / 名家 **虚构命名 only**。  
- 血统书 ≥3 代可查；出生与过户等写只追加可信日志（链可选，V1.0 最小存证即可，**勿用钱包阻断养成**）。  
- 育种小结：F、育种值倾向、是否朝选择目标移动。

### M4 — 轻竞技

- 家飞积分赛、短距路训公开赛、状态评分赛、新秀赛。  
- 表现因果：适性匹配 × 状态 × 训练准备 × 营养 × 小幅发挥波动；复盘指出最弱项。  
- 奖励：**仅巢币 + 物品**（禁止 USDT/法币奖池）。

### M5 — 经济与社交市场

- 货币：**巢币**为唯一结算货币。  
- **Apple IAP → 巢币**（及礼包 SKU）；无提现。  
- 商城：饲料、药品、用品、种蛋/幼鸽/种鸽、外观、有限成长加速。  
- 玩家交易抽成约 2%–5%；拍卖抽成约 5%–8%（可配置）。  
- 拍卖雏形：起拍/保留价/时长、流拍归还；轻量专场即可。

### M6 — 引导、图鉴、预告、打磨

- 新手必教喂训配治；赠「带小缺陷」教学鸽。  
- 图鉴与成就（治愈、育雏、上榜、拍卖成交、读复盘等）。  
- 「官方公棚即将开放」资格条预告；数据预留 `loftEntryEligible` / `lockedInLoftId` 等（见规格 §19），**不实装送棚**。  
- 中英切换；主要 UI 与关键邮件/收据文案双语。

### 时间标尺（初值，需做成可调配置）

| 体验 | 初值 |
|------|------|
| 孵化 | 4–8 小时真实时间 |
| 育雏至独立 | 24–48 小时 |
| 至轻竞技适龄 | 3–7 天 |
| 至「未来公棚适龄」展示 | 7–14 天（只展示） |

离线推进养护/孵化；训练不因离线自动练完。

## 明确禁止（V1.0）

- USDT / 链上支付 / 提现  
- 仿真场外、真实公棚运动员份额  
- 公棚建设令牌、玩家办赛  
- 官方多关公棚大奖赛（交鸽→清棚→关赛→鸽王）  
- 用随机「天降死亡」制造难度  
- 未授权真实名家/商标当品系名  
- 开箱直接发满级战神鸽压过养成  
- 把钱包/链做成进入养成的硬门槛  
- 擅自开工 V1.5+ 当主线

## 美术方向（给你与美术执行）

- **关键词**：干净、日照鸽棚、可信的动物与器材、轻松但不糊弄；「好玩的真实感」。  
- **避免**：纯 Q 版无结构的圆滚宠物；赛博霓虹赌感大厅；杂乱拟真到无法阅读状态。  
- **优先资产**：棚主界面、鸽卡、日检、血统书、训练/医疗反馈、轻竞技结算、拍卖行、商城、中英 UI 套件。  
- 鸽子需能区分羽色/性别/状态（病、疲劳）的可读信号；不必首周上高模电影级。  
- UI 一级入口按规格：我的棚 / 训练 / 赛事 / 市场 / 商城 / 图鉴·血统 / 我的。

1. **规格驱动**：功能旁注释或文档链到规格章节号。
